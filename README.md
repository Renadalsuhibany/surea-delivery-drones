# Surea Delivery Drones

## Overview

Surea Delivery Drones is an academic system design project for managing a fleet of drones used for local parcel delivery.

The system focuses on order scheduling, drone assignment, route optimization, real-time delivery tracking, customer notifications, and drone monitoring.

## System Features

* Customer registration and delivery order creation
* Delivery price estimation
* Real-time drone and parcel tracking
* Delivery status notifications
* Admin drone monitoring dashboard
* Drone maintenance alerts
* Weather-based delivery notifications
* Standard and express delivery options
* Customer ratings and feedback
